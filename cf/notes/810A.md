mathematical solution


rather than k, it's more right if we say we need the avg to be at least (k - 0.5)

so, let's say the initial count of the data is n and the new data we add would be counted as x, and to minimize the number of new number, we will always add k

so here is the case

we can make the initial equation like this
sum >= (k-0.5) . n
since k and n is constant, there is nothing we can change, so we add new variable
x: the count of added k

so the new equation would be
sum + kx >= (k-0.5) . (n+x)
and we could distribute it like this
sum + kx >= (k-0.5) . n + (k-0.5) . x
where (k-0.5) . n is the initial target with n number
using this structure, we can find x like this since the number of k and n is already provided
kx - (k - 0.5) * x >= (k - 0.5) * n - sum
(k - (k - 0.5)) * x >= (k - 0.5) * n - sum
(0.5) * x >= (k - 0.5) * n - sum
x >= ((k - 0.5) * n - sum) / 0.5
